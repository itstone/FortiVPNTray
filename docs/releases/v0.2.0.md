## FortiVPNTray v0.2.0 — Native Swift edition

FortiVPNTray is a native SwiftUI + AppKit menu bar VPN client, with a Rust connection helper and the external openfortivpn engine.

### Highlights

- Close the window to keep the VPN in the menu bar without a running Dock icon.
- Distinct connected/disconnected tray icons and a graphical popover with IP, duration, traffic history, rates and totals.
- Password and browser-based SAML profiles, Keychain passwords, certificate pins and system DNS fallback.
- Clear helper installation/version status, repair/uninstall actions and verified operation feedback.
- Compact native interface with inline profile editing.

### Download and install

**Apple Silicon only · macOS 13+**

1. Run `brew install openfortivpn` (expected path: `/opt/homebrew/bin/openfortivpn`).
2. Download `FortiVPNTray-native-arm64.zip`, unzip it and move `FortiVPNTray.app` to Applications.
3. Open Settings, install the connection helper with administrator permission, then create a Password or SAML profile.

The app is **ad-hoc signed, not Apple-notarized**. macOS may require approval under System Settings → Privacy & Security on first launch. There is no Intel build or Homebrew cask for this edition. Swift/Rust are required only when building from source.

Download `SHA256SUMS` alongside the ZIP and run `shasum -a 256 -c SHA256SUMS` to verify it.

Run one FortiVPNTray instance at a time, and do not connect multiple VPN clients concurrently. macOS may prompt for Keychain access when the app reads saved credentials.

The bundled helper version is 0.1.9. Automated tests/builds do not replace validation against your own gateway, corporate DNS, sleep/wake behavior or macOS version.
