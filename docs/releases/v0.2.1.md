## FortiVPNTray v0.2.1

- Fix New Profile and Save being disabled while a VPN session is active.
- Saving a new profile preserves the active connection and current profile selection.
- Existing profiles can be opened in a read-only view during a session, including expandable certificates and advanced arguments.
- Existing profiles remain protected from editing and deletion during a session; unavailable configuration storage still blocks saving.

Apple Silicon only, macOS 13+. Download `FortiVPNTray-native-arm64.zip` and verify it using `SHA256SUMS`. The app is ad-hoc signed, not Apple-notarized. Requires `/opt/homebrew/bin/openfortivpn`; bundled helper remains version 0.1.9.

Validation includes Swift core tests, Rust helper tests, and isolated AppKit smoke checks with a simulated connected session. A real VPN gateway session is not covered by these automated checks.
