## FortiVPNTray v0.2.2

- Creating, editing and viewing a profile now use the full window content area. The connection card and main footer are hidden until you return to the profile list.
- The profile header and action buttons stay visible while the form scrolls.
- Existing profiles remain read-only during a VPN session, and saving a new profile preserves the active connection.
- The main footer and About page display the actual bundled application version.

Apple Silicon only, macOS 13+. Download `FortiVPNTray-native-arm64.zip` and verify it using `SHA256SUMS`. The app is ad-hoc signed, not Apple-notarized. Requires `/opt/homebrew/bin/openfortivpn`; bundled helper remains version 0.1.9.

Validation: release build, signature/archive checks, and isolated AppKit smoke checks with screenshots of the actual main window in edit and read-only modes. Real VPN gateway validation is not included.
