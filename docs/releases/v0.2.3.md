## FortiVPNTray v0.2.3

- Connection errors no longer bring a hidden main window to the front when connecting or retrying from the menu bar.
- The menu bar keeps a message-review action available. Opening the main window displays the pending error.

Apple Silicon only, macOS 13+. Download `FortiVPNTray-native-arm64.zip` and verify it using `SHA256SUMS`. The app is ad-hoc signed, not Apple-notarized. Requires `/opt/homebrew/bin/openfortivpn`; bundled helper remains version 0.1.9.

Validation: 27 Swift core tests, 8 helper tests, 34 isolated AppKit smoke checks, release build, and signature/archive checks. Real VPN gateway validation is not included.
